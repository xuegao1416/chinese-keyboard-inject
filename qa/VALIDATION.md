# CKI 1.0 发布验证

本版在本地 25 个已知输入 ROM 上重新构建并运行补丁。24 个成功进入命名界面并完成运行检查；其中 7 个检测到中文字库并通过中英切换、整字删除和英文追加路线，17 个没有检测到中文字库并保留原版行为。`astral_emerald_v0.0.65` 的键盘窗口 API 与解析器支持的结构不同，因此被安全拒绝，不计入兼容宿主。结论只覆盖验证记录中的输入哈希。

这 25 项结果属于**构建后 ROM 的二进制注入验证**，其中包括 `pokeemerald-ch` 等 C／Thumb 重编译工程产物；不应解读成 CKI 的 C／Thumb SDK 已在 25 个源码工程中集成。SDK 当前单独完成了编译、链接和缓冲行为检查，宿主命名界面与存档流程仍需工程维护者接入和验证。25 个样本的文件标识和输入 SHA-256 见[重编译改版兼容证据](../docs/DECOMP_COMPATIBILITY.md)。

24 个成功宿主又完成了 27 步边界路线，均通过。3 个中文宿主额外验证了关闭界面标签的选项。23 项自动化检查覆盖共享 C 字符缓冲、源码导出、ARMv4T 链接、命令行、桌面流程、地址解析与打包内容。

机器可读的输入、输出、验证脚本及模拟器哈希和字库结果见 [validation.json](validation.json)。无字库宿主的运行日志与干净 ROM 完全一致，截图也没有新增墨迹。动画帧采样时相不同会导致截图存在差异，因此这里不宣称逐像素相同。

验证不包含 ROM 文件；本地捕获位于 `build/v2_matrix_verified/` 和 `build/v2_no_label_verified/`。本版不会注入中文字库，也不会扩展存档姓名字段。源码 SDK 仍需游戏工程接入绘制和编码回调；拼音输入与任意改版自动适配不在范围内。
